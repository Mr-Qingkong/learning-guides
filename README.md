# 学习指南合集（Learning Guides）

58 份跨领域的交互式进阶学习指南 + 软考专区，纯 HTML 实现、零外部依赖，双击即可在浏览器打开学习。

## 快速开始

- 直接打开 `index.html`，查看全部 58 份指南的入口（另附「软考专区」）。
- 每份指南面向**本科及以上**读者，按统一六段式组织内容，可直接连续阅读。
- **注意**：所有文件需保持在同一目录下（`index.html`、58 份指南、`软考/` 与 `_shared/` 文件夹），不要单独移动某个 HTML 文件。

## 每份指南的结构

所有指南已按同一套深度标准重写，一篇文章通常包含：

1. **原理与机制推导** —— 不停留在结论，而是还原到机制层，给出推导链或因果模型（数理类含公式推导）。
2. **前沿与研究进展** —— 该领域近年范式演进，附时间线，表述审慎、不夸大。
3. **跨学科视角** —— 与其他学科的交叉点，帮助建立知识网络。
4. **常见误区与边界条件** —— 对照式拆解常见错误认知，并说明结论的适用边界。
5. **速查卡** —— 12–18 条要点，支持一键复制。
6. **高阶练习清单** —— 8–10 道需推导、验证或动手实现的难题，可勾选并实时统计进度。

## 领域覆盖

**科技 · AI（01–03, 19–26）**：AI 提示词工程、Python 编程、数据分析、机器学习、大模型应用与智能体、Linux 与命令行、Git、SQL、算法与数据结构、计算机网络、信息安全。

**思维 · 表达（04, 09, 27–29）**：高效写作、批判性思维、演讲与口头表达、深度阅读方法、笔记与知识管理。

**效率 · 生活（05–08, 10, 30–38）**：高效学习法、时间管理、个人理财、英语学习、睡眠与精力、记忆术、运动科学、饮食营养、情绪与压力、习惯养成、人际沟通、谈判、求职面试、职业规划。

**通识 · 万象（11–18）**：天文学、地理学、世界历史、政治学、易经与阴阳五行、生物学、化学、物理与机械。

**人文 · 社会（39–44）**：经济学、心理学、哲学、社会学、法律、教育学。

**科学 · 方法（45–50）**：数学、统计学、人体与医学、大脑与神经科学、生态与环境、科学方法论。

**艺术 · 美学（51–58）**：音乐、美术与绘画、电影、摄影、建筑、文学、世界宗教、书法。

**软考专区**：系统分析师（软考高级）考点精讲与真题详解，13 章 + 论文写作专项，配 112 幅原理插图与 94 道真题详解。

## 特点

- 全宽铺满屏幕的响应式布局，桌面 / 移动端自适应。
- 每份指南均为**进阶**内容：原理推导、公式、真实数据、前沿进展与高阶练习，而非浅层科普。
- 全部本地资源，无需联网、无 CDN 依赖，可离线使用。
