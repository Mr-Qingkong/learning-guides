# 学习指南合集（Learning Guides）

18 份跨领域的交互式学习指南，纯 HTML 实现、零外部依赖，双击即可在浏览器打开学习。

## 快速开始

- 直接打开 `index.html`，查看全部 18 份指南的入口。
- 每份指南包含：核心概念、示意图（内联 SVG）、可一键复制的速查卡、可勾选的练习清单（带进度条）。
- **注意**：所有文件需保持在同一目录下（`index.html`、18 份指南与 `_shared/` 文件夹），不要单独移动某个 HTML 文件。

## 目录结构

```
learning-guides/
├── index.html            # 合集首页
├── 01-prompt-engineering.html
├── 02-python-basics.html
├── ...                   # 共 18 份指南
├── 18-physics.html
└── _shared/
    ├── style.css         # 共享样式（全宽布局、统一配色）
    └── guide.js          # 共享交互脚本（复制按钮、练习清单进度）
```

## 领域覆盖

**通用能力（01–10）**：AI 提示词工程、Python 编程、数据分析、高效写作、高效学习法、时间管理、个人理财、英语学习、批判性思维、睡眠与精力管理。

**学科知识（11–18）**：天文学、地理学、世界历史、政治学基础、易经与阴阳五行、生物学、化学、物理与机械。

**软考专区**：系统分析师（软考高级）考点精讲与真题详解，13 章 + 论文写作专项，配 112 幅原理插图与 94 道真题详解。

## 特点

- 全宽铺满屏幕的响应式布局，桌面 / 移动端自适应。
- 每份指南均为「进阶」内容：原理、公式、真实数据、案例与练习，而非浅层科普。
- 全部本地资源，无需联网、无 CDN 依赖，可离线使用。
